# Website-Personal-Productivity
Website ini saya bikin untuk membantu pengguna mengatur, merencanakan, dan memantau seluruh aktivitas sehari-hari dalam satu platform. Website ini menggabungkan fitur manajemen waktu, pengelolaan tugas, pelacakan kebiasaan, hingga pencapaian target dengan tampilan modern, minimalis, dan interaktif.
